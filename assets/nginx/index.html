Four-Layer Delivery Architecture

From user request to origin fetch, each layer has independent optimization strategies and can be enabled by business tier.

L1 Access and Scheduling Layer

Anycast and intelligent DNS work together to switch paths at regional level based on real-time network conditions.

L2 Caching and Transport Layer

Multi-level cache hit optimization, connection reuse, chunked transfer, and protocol upgrades for stable high-concurrency throughput.

L3 Security and Policy Layer

A unified policy center distributes access controls, WAF rules, and bot detection models with canary rollout support.

L4 Compute and Data Layer

Edge functions and object storage run in coordination to support near-user compute, origin offload, and low-latency data processing.
